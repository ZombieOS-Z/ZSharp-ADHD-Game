# Z# ADHD Game

This is the first game made with Z#, and is certified to be boreingly fun to people with ADHD.

# Details

This game uses Z# v1.0.2.1, which is downloaded off of the [Z# Website](https://www.zsharp.zombieos.com/), and if you already have it downloaded, you can just run the game!

The repository labels JavaScript and CSS. The reason for this is that Z# isnt defined as its own language yet by Linguist so JavaScript and CSS are the closest uses for Z#.

Read [.gitattributes](.gitattributes) for details.
